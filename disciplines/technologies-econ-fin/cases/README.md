# Кейсы дисциплины — страницы для лекций и семинаров

Строка каталога (`business-models.csv`, `cases.csv`) — сжатая версия кейса. Здесь лежит **развёрнутый
контент** под лекцию и семинар: тезисы по рамке курса, слайды, вопросы и раздел заданий.

| Кейс | Каталог | Страница | Задание | Досье |
|---|---|---|---|---|
| Red Bull | `bm01`, `ca08` | [md](red-bull/README.md) · [HTML](red-bull/index.html) | [`rb-02`](../../../assignments/templates/rb-02-red-bull-business-model.md) | [red-bull](../../../assignments/dossiers/red-bull/README.md) |

## Состав папки кейса

```
cases/<кейс>/
├── README.md     # источник правды: тезисы, цифры и статус проверки, вопросы, задания, реестр слайдов
├── index.html    # HTML-версия (file:// и GitHub Pages), держать в синхроне с README.md
└── slides/       # слайды под постоянными именами файлов
```

## Слайды обновляются

1. Новую версию слайда кладём **под тем же именем файла**. Ссылки из страницы, карточки задания и досье
   не ломаются.
2. Обновляем дату в таблице «Слайды» в `README.md` кейса и константу `SLIDES_VERSION` в `index.html`
   (она же сбрасывает кэш браузера).
3. Если поменялись тезисы, правим `README.md`, `index.html` и отмечаем новую версию в `changelog.md`
   досье. Следующая выдача задания пойдёт по новой редакции.

## Новый кейс

1. Скопировать структуру `red-bull/`, поменять тексты и слайды.
2. Добавить страницу в `CASE_PAGES` в [`../site/build.py`](../site/build.py) и пересобрать курс. Тогда
   у карточки кейса в `course.html` появится ссылка на страницу.
3. Завести карточку задания по [шаблону](../../../assignments/templates/_card-template.md) и, если
   кейс живой, досье в [`assignments/dossiers/`](../../../assignments/dossiers/README.md).
