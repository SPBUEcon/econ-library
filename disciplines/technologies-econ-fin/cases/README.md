# Кейсы дисциплины — страницы для лекций и семинаров

Строка каталога (`business-models.csv`, `cases.csv`) — сжатая версия кейса. Страница кейса — **сборка над
тезисами** ([`theses/`](../../../theses/README.md)): содержание (слайды, комментарии, вопросы, что проверить)
живёт в тезисах, а кейс добавляет то, что относится к компании целиком: паспорт, досье, маршрут заданий,
исходные слайды автора и цикл обновления. HTML кейса не пишется руками — его собирает
`python theses/site/build.py`.

## Состав папки кейса

```
cases/<кейс>/
├── README.md     # источник сборки (frontmatter `kind: кейс`): паспорт, список тезисов, задания, реестр слайдов
├── index.html    # сгенерировано: страница кейса с каруселями тезисов
├── slides.html   # сгенерировано: слайды всех тезисов кейса для показа и PDF
└── slides/       # исходные слайды автора под постоянными именами файлов
```

## Слайды обновляются

1. Новую версию слайда кладём **под тем же именем файла**. Ссылки из страницы, карточки задания и досье
   не ломаются.
2. Обновляем дату в таблице «Слайды» в `README.md` кейса.
3. Сверяем с новой версией тезисы кейса (`theses/thNN-…/README.md`), пересобираем
   `python theses/site/build.py` и отмечаем новую версию в `changelog.md` досье. Следующая выдача
   задания пойдёт по новой редакции.

## Новый кейс

1. Собрать тезисы компании в [`theses/`](../../../theses/README.md), затем скопировать `red-bull/README.md`:
   frontmatter `kind: кейс`, паспорт, раздел «Тезисы» со списком `thNN`, задания, реестр слайдов.
   Пересобрать `python theses/site/build.py`.
2. Добавить страницу в `CASE_PAGES` в [`../site/build.py`](../site/build.py) и пересобрать курс. Тогда
   у карточки кейса в `course.html` появится ссылка на страницу.
3. Завести карточку задания по [шаблону](../../../assignments/templates/_card-template.md) и, если
   кейс живой, досье в [`assignments/dossiers/`](../../../assignments/dossiers/README.md).
