# Дисциплина «Технологии (информационные системы в экономике и финансах)»

База знаний дисциплины, которую в Мастерской ведёт Д. Хан. Здесь собраны **темы, кейсы, модели,
методологии** и другой базовый контент, который читается на лекциях, разбирается на семинарах, даётся
в презентациях и спрашивается у студентов. Контент собран из ~14 авторских презентаций и разложен в
**каталог исходных данных** ([`catalog/`](catalog/)), по которому его можно группировать и
переиспользовать.

## Зачем это

Дисциплина готовит **архитекторов экономических моделей** с опорой на технологические трансформации.
Логика курса (см. [`program/governance.md`](../../program/governance.md)): индустриальная экономика
*считает*, информационная *анализирует*, постинформационная *собирает*. ИИ забирает аналитику и
контент — экономисту остаётся сборка моделей, команд и условий, при которых результат не может не
случиться. Дисциплина даёт язык и инструменты этой сборки.

семестра»). По ним же в каталоге сгруппированы все сущности (поле `block`):

| Блок | `block` | О чём | Опорная заметка |
|---|---|---|---|
| Постинформационный переход | `transition` | Смена укладов; воронка·лейка·хлопушка; три уклада; матрица отраслей | [notes/postinformational-transition.md](notes/postinformational-transition.md) |
| Технологический ландшафт | `landscape` | Стек инфраструктуры; фронтирные технологии; кванты, DLT; оператор инфраструктуры | [notes/quantum-communications-case.md](notes/quantum-communications-case.md) |
| ИИ и модели бизнеса | `ai-business` | ИИ и трансформация рынков; AI-native; кейсы компаний; стратегии генерации ДС | [notes/ai-native-and-markets.md](notes/ai-native-and-markets.md) |

## Что внутри

### [`catalog/`](catalog/) — исходные данные (CSV)
«Источник правды», из которого собираются лекции, семинары и задания. Все файлы описаны в
[`catalog/README.md`](catalog/README.md).

| Файл | Строк | Что |
|---|---|---|
| [`topics.csv`](catalog/topics.csv) | 28 | Темы / лекционные блоки |
| [`technologies.csv`](catalog/technologies.csv) | 10 | Технологии, которые разбираются (ИИ, квантовые, блокчейн/DLT и др.) |
| [`concepts.csv`](catalog/concepts.csv) | 34 | Концепты и мыслительные модели-фреймворки |
| [`methodologies.csv`](catalog/methodologies.csv) | 13 | Методологии |
| [`business-models.csv`](catalog/business-models.csv) | 13 | Кейсы компаний (модели бизнеса) |
| [`cases.csv`](catalog/cases.csv) | 10 | Прикладные и инфраструктурные кейсы |
| [`industries.csv`](catalog/industries.csv) | 15 | Матрица укладов по отраслям |
| [`questions.csv`](catalog/questions.csv) | 24 | Банк вопросов студентам |
| [`sources.csv`](catalog/sources.csv) | 14 | Презентации-первоисточники (провенанс) |

### [`notes/`](notes/) — опорные заметки
Развёрнутые тексты по флагманским темам для подготовки к лекциям и семинарам. Каждая заметка ссылается
на строки каталога.

### [`site/`](site/) — HTML-курс
Самодостаточная страница [`site/course.html`](site/course.html): курс с разделами (блоки, темы,
концепты, методологии, модели бизнеса, кейсы, матрица отраслей, вопросы, источники), фильтром по блокам
и поиском по всему содержимому. Собирается из каталога скриптом [`site/build.py`](site/build.py) —
данные встроены в страницу, работает по `file://` без сервера. После правки CSV пересоберите:

```bash
python disciplines/technologies-econ-fin/site/build.py
```

## Как пользоваться

- **Собрать лекцию по блоку:** отфильтровать `topics.csv`, `concepts.csv`, `methodologies.csv` по
  нужному `block`; подтянуть кейсы из `business-models.csv` / `cases.csv`.
- **Подготовить семинар:** взять кейс + связанные концепты (`related_concepts`) + вопросы из
  `questions.csv` по тому же `topic_id`/`block`.
- **Найти первоисточник:** по `source_ids` строки → `sources.csv` → конкретная презентация и её дата.
- **Дополнить каталог:** добавить строку с новым `*_id`, проставить `block` и `source_ids`; проверить
  целостность скриптом из [`catalog/README.md`](catalog/README.md).

## Связь с Мастерской

- Дисциплину читают два трека (потоки × семестр) — [`tracks/`](../../tracks/README.md):
  [`econ-3`](../../tracks/econ-3/README.md) (Экономика, 3 к.) и [`bi-4`](../../tracks/bi-4/README.md)
  (Бизнес-информатика/ИСЭ, 4 к.). Планы, контент занятий и доклады прогонов — там.
- Дисциплина ИСЭ (4 к.) стартует 18.09.2026 и идёт параллельно основному ходу —
  [`program/calendar.md`](../../program/calendar.md).
- Лекционная линия осени 2026 (эксперты партнёров) — там же; этот каталог даёт **базовый**
  (авторский) слой контента, поверх которого идут экспертные лекции.
- Кейсы и методологии переопыляются с воркстримами ([`workstreams/`](../../workstreams/README.md)):
  например, квантовая инфраструктура, ИИ-агенты, модели бизнеса партнёров.

## Провенанс и оговорки

- **Первоисточник контента — авторские презентации Д. Хан** (`sources.csv`). Оригиналы **приватны и в
  публичный репозиторий не добавляются** (личные материалы, персональные данные на слайдах, размер
  ~320 МБ). В git хранится только **структурированное извлечение** (`catalog/`, `notes/`, извлечено
  2026-09-24) — это и есть открыто доступный слой контента.
- **Доступ к оригиналам — по запросу** у владельца дисциплины / мастера. Держите деки локально в
  `source-private/` (папка в [`.gitignore`](../../.gitignore), в репозиторий не попадает) или во
  внешнем закрытом хранилище. Файлы `.pptx` под `disciplines/` игнорируются git — случайно
  закоммитить дек нельзя. Если репозиторий позже закроют, можно добавить PDF-экспорты (без
  персональных данных) в папку `source/` по конвенции [`program/source/`](../../program/source/).
- **Цифры (обороты, инвестиции, охваты, метрики проектов) взяты со слайдов и вторичны.** Перед
  использованием в студенческих работах их нужно проверить по первоисточнику и оформить ссылку по
  [`rules/sources-and-citation.md`](../../rules/sources-and-citation.md). В каталоге такие значения
  помечены «(цифры со слайдов — проверить)».
- Каталог собран с помощью ИИ-ассистента и требует ревью
  ([`rules/ai-usage.md`](../../rules/ai-usage.md)); ответственность за факты — на команде.
- Персональные данные (контакты автора со слайдов) в каталог не переносятся
  ([`rules/data-collection.md`](../../rules/data-collection.md)).
