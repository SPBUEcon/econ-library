# Дисциплина «Технологии (информационные системы в экономике и финансах)»

Ведёт Д. Хан. Здесь — база знаний дисциплины: темы, кейсы, модели и методологии из ~14 авторских
презентаций, разложенные в каталог (таблицы) и опорные заметки. Из них собираются лекции, семинары и
задания.

**[Смотреть на сайте →](https://spbuecon.github.io/econ-library/theses/site/index.html)** — витрина
«Тезисы и сборки»: весь каталог с поиском и фильтром по блокам, банк вопросов и источники.

## Зачем это

Дисциплина готовит **архитекторов экономических моделей** с опорой на технологические трансформации.
Логика курса (см. [`program/governance.md`](../../program/governance.md)): индустриальная экономика
*считает*, информационная *анализирует*, постинформационная *собирает*. ИИ забирает аналитику и
контент — экономисту остаётся сборка моделей, команд и условий, при которых результат не может не
случиться. Дисциплина даёт язык и инструменты этой сборки.

## Как пользоваться

- **Собрать лекцию по блоку:** отобрать в `topics.csv`, `concepts.csv`, `methodologies.csv` строки
  нужного блока; добавить кейсы из `business-models.csv` / `cases.csv`.
- **Подготовить семинар:** взять кейс, связанные концепты (`related_concepts`) и вопросы из
  `questions.csv` по той же теме или блоку.
- **Найти первоисточник:** по `source_ids` строки → `sources.csv` → конкретная презентация и её дата.
- **Дополнить каталог:** добавить строку с новым `*_id`, проставить блок и `source_ids`; как проверить —
  в [описании каталога](catalog/README.md#проверка-целостности).
