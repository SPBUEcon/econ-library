# econ-library

Учебные материалы и ресурсы Экономического факультета СПбГУ.

## Структура

```
econ-library/
├── courses/          # материалы по предметам
│   ├── _template/    # шаблон папки предмета
│   ├── year-1/       # semester-1, semester-2
│   ├── year-2/       # semester-3, semester-4
│   ├── year-3/       # semester-5, semester-6
│   └── year-4/       # semester-7, semester-8
├── projects/         # курсовые, командные проекты, ВКР
└── guides/           # гайды, ссылки, FAQ
```
