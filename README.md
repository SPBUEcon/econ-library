# econ-library — среда управления Мастерской «Технологии в экономике»

Единый репозиторий Мастерской «Технологии в экономике» (Экономический факультет СПбГУ, осень
2026) и её **воркстримов**: материалы, данные, скилы, артефакты гейтов, цифровой след. Здесь же —
учебные материалы курсов, командные кейсы и проектная работа студентов.

> Проект студенческий и неофициальный. Все данные собираются из открытых источников.

> **🧭 Общий дашборд всей активности** (сущности, ссылки, статусы) — [`DASHBOARD.md`](DASHBOARD.md) ·
> визуальная витрина [`program/site/dashboard.html`](program/site/dashboard.html).

## Что такое мастерская

Не курс, а мастерская: команды в воркстримах собирают живые модели бизнеса, рынка и территории
вместе с реальными партнёрами. **Воркстрим** — единица управления, живёт дольше семестра;
**семестр = один ход**, размеченный гейтами **G0→G5**. Полный концепт —
[`program/concept.md`](program/concept.md); модель управления курсом —
[`program/governance.md`](program/governance.md).

## Как войти в мастерскую

1. Посмотри [витрину воркстримов](program/site/workstreams_board.html) и [доску «воркстрим × гейт»](workstreams/board.md): что происходит и на каком гейте.
2. Выбери воркстрим из [карты воркстримов](workstreams/README.md).
3. Заполни форму — [«Заявка на вход в воркстрим»](.github/ISSUE_TEMPLATE/join-workstream.md): воркстрим + роль + навыки. Или напиши контакт из карточки воркстрима.
4. **24.09 — G1**, сборка команд. Первое занятие — **17.09.2026** (G0).

Подробно — гайд [«Как включиться в воркстрим»](guides/how-to-join.md). Роли — [`roles/README.md`](roles/README.md). Правила — [`rules/`](rules/).

## Структура

```
econ-library/
├── program/       # слой 1: программа/курс — концепт, модель управления, гейты, календарь, HTML, источники
├── workstreams/   # слой 2: воркстримы — карта + карточки + шаблон; слой 3 (команды) внутри них
├── roles/         # роли команды и роли партнёра
├── registry/      # реестр: участники, команды, назначения ролей по семестрам
├── partners/      # партнёры и вузы-партнёры (+ проект с Ингосстрахом)
├── meetings/      # протоколы общих встреч мастерской
├── rules/         # правила: данные, источники, команда, ИИ, жизненный цикл воркстрима
├── courses/       # материалы по предметам (year-1 … year-4)
├── disciplines/   # базы знаний дисциплин: темы, кейсы, модели, методологии (каталоги + заметки)
├── tracks/        # формальные треки: группы × семестры — планы, занятия, доклады, отчётность
├── projects/      # курсовые, командные проекты, ВКР
├── cases/         # командные кейсы
├── guides/        # гайды, ссылки, FAQ
├── DASHBOARD.md   # общий дашборд всей активности (сущности, ссылки, статусы)
└── CLAUDE.md      # инструкции для Claude Code
```

## Три слоя архитектуры

| Слой | Ведут | Где |
|---|---|---|
| Программа · курс | Мастер + факультет | [`program/`](program/) |
| Воркстрим | Партнёр + шерпа | [`workstreams/`](workstreams/) |
| Команды и участники | Капитан + студенты | внутри каждой папки воркстрима |

## С чего начать

1. Прочитай [концепт мастерской](program/concept.md) и [карту воркстримов](workstreams/README.md).
2. Посмотри [правила проекта](rules/) и [как участвовать](CONTRIBUTING.md).
3. Новый воркстрим — с копии [шаблона](workstreams/_template/); новый кейс — с копии
   [шаблона кейса](cases/_template/).
