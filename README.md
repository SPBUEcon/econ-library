# Мастерская «Технологии в экономике»

Репозиторий мастерской Экономического факультета СПбГУ. Здесь мы ведём **воркстримы** —
направления, в которых команды студентов вместе с партнёрами решают реальные задачи. У каждого
воркстрима здесь своя карточка, задания, данные, результаты и вся история работы.

> Проект студенческий и неофициальный. Данные — только из открытых источников.

## Если вы здесь впервые

- **Студенту** — [гайд для студента](https://spbuecon.github.io/econ-library/guides/): понятия,
  какие воркстримы есть и как присоединиться.
- **Все воркстримы** — [витрина](https://spbuecon.github.io/econ-library/program/site/workstreams_board.html)
  на сайте или [карта воркстримов](workstreams/README.md) здесь, на GitHub.
- **Записаться** — [форма записи на витрине](https://spbuecon.github.io/econ-library/program/site/workstreams_board.html#apply): воркстрим, формат
  участия и пара слов о себе. Заявка уйдёт через GitHub, ответ придёт комментарием в ней.
- **Сайт мастерской** — [spbuecon.github.io/econ-library](https://spbuecon.github.io/econ-library/):
  группы, партнёры, материалы и поиск по всему репозиторию.

## Как вносить изменения

Все изменения — через Pull request: ветка → PR → проверка капитаном или шерпой → слияние.
Подробно — [как участвовать](CONTRIBUTING.md). Новый воркстрим заводится с копии
[шаблона](workstreams/_template/).
