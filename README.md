# econ-library

Учебные материалы, командные кейсы и проектная работа студентов Экономического факультета СПбГУ.

## Структура

```
econ-library/
├── CLAUDE.md          # инструкции для Claude Code
├── CONTRIBUTING.md    # как участвовать в работе
├── rules/             # правила проекта: данные, источники, команды, ИИ
├── .claude/agents/    # ИИ-агенты для Claude Code
├── courses/           # материалы по предметам (year-1 … year-4)
├── projects/          # курсовые, командные проекты, ВКР
├── cases/             # командные кейсы
├── partners/          # проекты с компаниями (Ингосстрах)
└── guides/            # гайды, ссылки, FAQ
```

## С чего начать

1. Прочитайте [правила проекта](rules/).
2. Посмотрите [как участвовать](CONTRIBUTING.md).
3. Новый кейс начинайте с копии [шаблона](cases/_template/).

> Проект студенческий и неофициальный. Все данные собираются из открытых источников.
