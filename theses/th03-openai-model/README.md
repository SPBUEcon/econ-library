# th03 · Модель бизнеса OpenAI

> **Мы строим супермашину для трансформации всех глобальных рынков.**
>
> **Слайды:** [`slides.html`](slides.html) — чистый тезис для показа и PDF.
> **Карточка:** [`index.html`](index.html) — слайды с подсветкой проверок, комментарии, вопросы, задания.

OpenAI как «архитектор новых рынков» и модель гиперигрока (`c18`): совокупный охват «весь мир», ИТ-
инфраструктура и финансовое плечо складываются в машину трансформации рынков. Тезис показывает модель по
трём укладам, путь компании и денежную машину ИИ вокруг неё. Входит в серию
[«Постинформационные модели бизнеса»](../assemblies/pim-business-models.md).

## Слайд 1. OpenAI по трём укладам
<!-- layout: columns -->
<!-- logo: assets/openai-logo.png -->

| Индустриальный · считает | Информационный · анализирует | Постинформационный · собирает |
|---|---|---|
| Совокупный охват клиентов — <mark>800 млн человек</mark> по всему миру | Создание экосистемы экосистем | Трансформация всех глобальных рынков |
| | | Участие в прорывных стартапах с чемпионами мира |
| | | Управление замыслами через сеть архитекторов |
| | | Хостинг сети суперкоманд |

**Формула:** мы строим экосистему экосистем с совокупным охватом клиентов в весь мир, ИТ-инфраструктурой
по всему миру, огромным финансовым плечом. Мы строим супермашину для трансформации всех глобальных рынков.

<!-- notes -->

Слайд почти пустой слева и плотный справа — и это часть тезиса. Индустриальный слой OpenAI — охват, то
есть масштаб, информационный — экосистема. Основное содержание модели — в постинформационной колонке:
OpenAI не продаёт продукт, а собирает рынки через сеть архитекторов, стартапов и суперкоманд (`c28`).

Формула совпадает с моделью гиперигрока (`c18`): охват «весь мир» + ИТ-инфраструктура + финансовое
плечо = машина трансформации всех глобальных рынков. Та же модель — у Сбера (`th04`).

## Слайд 3. Денежная машина ИИ

```cycle
OpenAI · $500 млрд -облако за $300 млрд-> Oracle -десятки млрд на чипы-> Nvidia · $4,5 трлн -до $100 млрд инвестиций-> OpenAI
```

- **AMD:** <mark>6 ГВт GPU для OpenAI</mark>, опцион OpenAI на покупку <mark>до 160 млн акций AMD</mark>
- **Суперкоманды:** Cognition — четыре чемпиона мира ICPC, включая Геннадия Короткевича (ИТМО),
  капитализация <mark>$10 млрд</mark>; лид-инвестор — Founders Fund
- **Государство:** комиссия Конгресса США, 2024 — первая рекомендация: <mark>программа уровня
  «Манхэттенского проекта» для гонки за AGI</mark>

<!-- notes -->

Денежные потоки замыкаются: OpenAI покупает облачные мощности у Oracle, Oracle покупает чипы у Nvidia,
Nvidia инвестирует в OpenAI. Капитализация участников растёт вместе с контрактами друг с другом — это и
есть «огромное финансовое плечо» из формулы. Схема на слайде автора — карта Bloomberg News «How Nvidia
and OpenAI Fuel the AI Money Machine»; здесь из неё оставлен главный цикл.

Вокруг цикла — две опоры. Суперкоманды (`c28`): чемпионы ICPC как неотчуждаемый ресурс, вокруг которого
собирается капитал (`bm13`). Государство: AGI как цель национального уровня. Вопрос 3 — что из этого
устойчиво, а что держится на ожиданиях.

### Что проверить

Утверждения взяты из авторской презентации и по первоисточникам не проверены. В карточке они
подсвечены на слайдах, в чистых слайдах подсветки нет. Цифры ИИ-рынка меняются быстро: у каждой —
дата, на которую она верна.

| Утверждение | Слайд | Статус | Что уточнить |
|---|---|---|---|
| Совокупный охват 800 млн человек | 1 | не проверено | Чья метрика (еженедельные активные пользователи?), на какую дату, заявление компании или оценка |
| Состав основателей 2015: Маск, Тиль, Альтман, Amazon | 2 | не проверено | Сверить с анонсом основания OpenAI (декабрь 2015): кто был сооснователем, а кто спонсором |
