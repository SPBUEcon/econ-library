# Программа — слой 1 Мастерской «Технологии в экономике»

Это **слой «Программа · курс»** архитектуры мастерской (ведут мастер + факультет): ритм
семестра, гейтовые события, состав воркстримов, большой воркшоп и демо-день.

Три слоя архитектуры:

1. **Программа · курс** — этот раздел.
2. **Воркстрим** (партнёр + шерпа) — [`../workstreams/`](../workstreams/).
3. **Команды и участники** (капитан + студенты) — внутри каждой папки воркстрима.

## Ключевое

- **Единица управления — воркстрим** (живёт дольше семестра). **Семестр = один ход**,
  размеченный гейтами G0→G5.
- **Первое занятие — 17.09.2026** (G0). **Сборка команд — 24.09 (G1).**
- **Среда мастерской = этот репозиторий** `econ-library`: материалы, данные, скилы, артефакты
  гейтов, цифровой след.

## Как войти

1. Выбери воркстрим из [карты](../workstreams/README.md).
2. Заполни форму — воркстрим + роль + навыки.
3. Войди в репозиторий и канал мастерской.
4. 24.09 — G1, сборка команд.
