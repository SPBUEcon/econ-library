# Программа — слой 1 Мастерской «Технологии в экономике»

Это **слой «Программа · курс»** архитектуры мастерской (ведут мастер + факультет): ритм
семестра, события, состав воркстримов, большой воркшоп и демо-день.

Три слоя архитектуры:

1. **Программа · курс** — этот раздел.
2. **Воркстрим** (партнёр + шерпа) — [`../workstreams/`](../workstreams/).
3. **Команды и участники** (капитан + студенты) — внутри каждой папки воркстрима.

## Ключевое

- **Воркстрим — тематический поток** (живёт дольше семестра): формула · инверт · узлы ·
  участники · хроника. **Гейтов нет** (отменены 2026-10-09). Задания — на [стендах](../stands/README.md).
- **Первое занятие — 17.09.2026.** **Сборка команд — 24.09.**
- **Среда мастерской = этот репозиторий** `econ-library`: материалы, данные, скилы, стенды,
  цифровой след.

## Как войти

1. Посмотри [витрину воркстримов](site/workstreams_board.html) и [стенды](../stands/README.md).
2. Выбери воркстрим из [карты](../workstreams/README.md).
3. Заполни форму — [«Заявка на вход»](../.github/ISSUE_TEMPLATE/join-workstream.md): воркстрим + роль + навыки.
4. Сделай первый вклад на стенде — [механики вовлечения](../stands/engagement.md).

Подробно — гайд [«Как включиться в воркстрим»](../guides/how-to-join.md).
