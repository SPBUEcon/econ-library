## Почему этот стенд первый

- **Все три слоя естественны.** ГИС — это одновременно информационная система (слой Ф), пространственная
  аналитика (слой И) и инструмент городских решений и коалиций (слой П).
- **Есть реальный носитель задачи и технолог:** Спорткомитет СПб формулирует три вопроса, Геоинтеллект
  держит инструмент и экспертизу.
- **Есть мосты в реальность с датами:** интенсив 21.10, открытая встреча в Музее спорта 29.10,
  демо-день 16.12 ([дорожная карта](../../workstreams/sport-spb/README.md)).
- **Задания уже есть:** `sp-01…sp-16` в [архиве](../../assignments/catalog/templates.csv) — их нужно
  только разложить по слоям.
- **Переопыление:** тот же технолог у [«Биеннале карт»](../../workstreams/cartography-biennale/README.md)
  и флагмана «Кибер-фиджитал арена».

## Замысел (инверт)

Сейчас решения о спортобъектах принимаются ситуативно, житель не знает, что есть рядом, а данные о
предложении разбросаны по реестрам. Через несколько ходов на стенде должна сложиться конфигурация:

- **открытая пространственная модель** доступности и дефицита, которую можно воспроизвести и
  обновить (не закрытый отчёт подрядчика);
- **язык решений:** Комитет обсуждает участок через охват населения и дефицит по категориям, а не
  через мнение;
- **житель как актор:** публичная карта и обратная связь — спрос становится видимым;
- **коалиция вокруг модели:** Комитет, районы, Геоинтеллект, частные клубы, вузы (студенческие
  команды как постоянный «отдел аналитики»), инвесторы в спортобъекты.

## Слой Ф — фундамент ИС

Стенд — это информационная система. Её архитектура на ход:

```
портал Спорткомитета · OSM · открытые данные СПб · Росстат
  --> сбор и геокодирование (скрипты в репозитории)
  --> data/raw (неизменно) --> data/processed (GeoJSON, CSV)
  --> модели доступности (изохроны по УДС)
  --> представления: карты, атлас района, прототип публичной карты
  --> сборка и публикация (GitHub Pages)
```

| Компонент | Что это | Где | Статус |
|---|---|---|---|
| Сбор реестра | Выгрузка портала Спорткомитета (https://komsport.spb.ru/portal/sportobject/), геокодирование | скрипт + `data/` воркстрима | нет |
| Хранение данных | `data/raw` → `data/processed`, форматы CSV и GeoJSON | [`workstreams/sport-geo/data/`](../../workstreams/sport-geo/data/) | заведено, пусто |
| Движок доступности | Изохроны 5/10/15 мин по улично-дорожной сети (открытые инструменты — *выбрать*) | репозиторий | нет |
| Публикация | Статические карты и страницы, сборка в CI | GitHub Pages | инфраструктура есть |
| Референс промышленного решения | Геоинтеллект.Платформа: публичный геосервис, тепловая карта, закрытый модуль, рабочее место администратора, API с ГИС города (ЕГИС СОЗ, ГИС ЭЛП, РГИС/КИО) | [КП](../../partners/komsport-spb/data/raw/kp-geointellect-2026-09-18.txt) | референс, не закупка |

**Процесс партнёра (AS-IS)** — как сейчас принимается решение о размещении объекта и откуда берутся
данные о нём: *заполнить* после встречи с Комитетом. Здесь же — точка встраивания модели.

Компетенции ИС, на которые опирается стенд: архитектура ИС (схема выше и сравнение с КП),
репозитории и PR, сборки (воспроизводимый конвейер данных), интеграции и API (источники города),
управление проектами (задачи по барьерам). Носители — прежде всего команды `bi-4`.

## Вовлечение

Механики — [`../engagement.md`](../engagement.md).

**Студенты на занятии (Н0):**

- *Охота на пометки* — сверка показателей ГП-498 и цифр КП по первоисточнику (b3, `sp-13`).
- *Ставка дня* — «какой район самый дефицитный по детскому спорту»; разрешается моделью b2.
- *Агент на паре* — агент «житель» ищет секцию для ребёнка 9 лет в районе N; разбор, где карта не помогла (b5).
- *Сборка за пару* — скрипт геокодирования одного района (`bi-4`, слой Ф, b1).

**Студенты в поле (Н1–Н2):**

- *Краудсорсинг-разметка* — каждый студент потока размечает площадки своего двора и квартала по единому протоколу (тип, покрытие, состояние, доступность; фото без людей). Поток за неделю даёт слой, который команде `sp-07` не собрать за семестр (b1).
- *Маршрут* — пройти расчётную 10-минутную изохрону до ФОК и отметить барьеры: закрытые переходы, заборы, ж/д (b2).
- *Тайный покупатель* — записаться в бесплатную секцию через портал и по телефону; протокол шагов и сроков (b5, `sp-04`).
- *Точка на событии* — стойка стенда на открытой встрече 29.10: карта на экране, короткий опрос посетителей.
