# Встречи мастерской

Итоги общих встреч мастерской (не привязанных к одному воркстриму) в формате
`ГГГГ-ММ-ДД-meeting.md`: участники, решения, кто что делает к какому сроку.

Встречи по конкретному воркстриму — в `workstreams/<воркстрим>/meetings/`; по партнёру Ингосстрах
— в [`../partners/ingosstrakh/meetings/`](../partners/ingosstrakh/meetings/).

Правило — [`../rules/team-work.md`](../rules/team-work.md). Решения фиксируются здесь, а не в
мессенджерах.
