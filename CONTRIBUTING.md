# Как участвовать

## Порядок работы

1. Задача заводится во вкладке **Issues** по шаблону «Задача».
2. Исполнитель назначает себя (Assignees).
3. Работа ведётся в отдельной ветке: `имя/короткое-описание`, например `anna/ingosstrakh-market-data`.
4. Готовый результат отправляется через **Pull request**.
5. Минимум один участник команды проверяет PR, после этого он принимается.

## Работа в воркстриме

- Работа мастерской идёт через **воркстримы** ([`workstreams/`](workstreams/)); воркстрим —
  единица управления, семестр — один ход по гейтам G0→G5.
- Новый воркстрим — с копии [`workstreams/_template/`](workstreams/_template/): заполнить
  карточку, добавить строку в [карту](workstreams/README.md) и партнёра в
  [реестр](partners/README.md).
- Артефакты гейтов складываются в `workstreams/<воркстрим>/gates/`; данные — в `data/raw/`
  (неизменны) и `data/processed/`; итоги встреч — в `meetings/`.
- Вклад виден через **цифровой след**: коммиты, артефакты гейтов, участие — основа оценки.
- Подробнее — [`rules/workstream-lifecycle.md`](rules/workstream-lifecycle.md).

## Именование

- Папки и файлы: латиница, нижний регистр, через дефис: `market-analysis.md`.
- Воркстримы: латиница через дефис, например `phygital-sport`.
- Кейсы: `год-сезон-название`, например `2026-fall-insurance-market`.
- Даты в именах файлов: `ГГГГ-ММ-ДД`, например `2026-09-17-meeting.md`.

## Что нельзя загружать

- Персональные данные людей.
- Платные материалы и чужие работы без разрешения.
- Файлы больше 25 МБ — дайте ссылку на них.
- Пароли, токены, ключи API.

Подробнее — в папке [rules](rules/).
