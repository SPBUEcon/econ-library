# Обработанные данные Спорткомитета СПб

Очищенные и обработанные выборки с описанием, что сделано; источник исходников — в
[`../raw/`](../raw/) и на портале Спорткомитета. См.
[`../../../../rules/data-collection.md`](../../../../rules/data-collection.md).

Планируемые наборы (заводятся командой по мере работы):
- реестр спортобъектов СПб (геокодированный) — из портала Спорткомитета;
- выборка целевых показателей ГП-498 — **после сверки по первоисточнику** (см. `../raw/README.md`);
- медиа/канальный срез (задача 2) — из открытых источников, без персональных данных.
