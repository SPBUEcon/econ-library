## Что делаем для партнёра

Спорткомитет несёт два сквозных потока задач (сформулированы партнёром). Каждый разложен на **два
горизонта** и ведётся отдельным воркстримом:

1. **Развитие инфраструктуры спорта** → воркстрим [`sport-geo`](../../workstreams/sport-geo/).
   ГИС-анализ и доказательное планирование размещения спортивных объектов (равномерность,
   доступность, дефицит по видам спорта и категориям населения). Ходы решения опираются на
   коммерческое предложение Геоинтеллекта (см. [`tasks/task-1-geoanalytics.md`](tasks/task-1-geoanalytics.md)).
2. **Развитие инфраструктуры вовлечения населения в спорт** → воркстрим
   [`sport-engagement`](../../workstreams/sport-engagement/). Стратегия управления каналами
   коммуникации, связка инфраструктуры и событийности с аудиторией и обратной связью, сквозная
   система показателей (см. [`tasks/task-2-engagement.md`](tasks/task-2-engagement.md)).

Общая рамка домена, связь двух задач и общий контур показателей — поток-хаб
[«Развитие территорий»](../../workstreams/territories/).
