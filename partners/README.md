# Партнёры

Партнёр — носитель суперзадачи с реальной ставкой. Через партнёров живут воркстримы мастерской
(см. [`../workstreams/README.md`](../workstreams/README.md)). Роли партнёра — Владелец воркстрима ·
Эксперт · Шерпа · Кадровый потребитель ([`../roles/README.md`](../roles/README.md)).

## Уровни участия партнёра

Участие — обмен, честный в обе стороны. Уровни комбинируются (якорный партнёр обычно занимает 2–3
сразу) и образуют лестницу вовлечения: эксперт → кадровый потребитель → шерпа → владелец. Полная
матрица (вклад / ценность / ритм / порог / что принимает) — [`../program/governance.md`](../program/governance.md) § 8.

| Уровень | Вклад | Что принимает |
|---|---|---|
| **01 · Эксперт** | Лекции, семинары, экспертные оценки моделей на ревью и демо | Ревьюер архитектурного ревью и демо |
| **02 · Кадровый потребитель** | Профиль запроса к кадрам/командам; стажировки, офферы | Наблюдатель демо |
| **03 · Шерпа** | Сотрудник партнёра ведёт команду или узел стенда | Сборку команды, поле, передачу наследства |
| **04 · Владелец воркстрима** | Барьеры со ставкой, доступ к полю и данным, утилизация результатов | Вердикты по своим барьерам |

Ступени с меньшим порогом (читатель дайджеста → ответчик на «три вопроса» → поставщик барьера →
поставщик данных D0–D6 → гость моста → держатель ставки → со-куратор стенда) —
[механики вовлечения](../stands/engagement.md).

**Один связной на партнёра** независимо от числа уровней: один контакт, один дайджест, одно место
в совете партнёров. «Пакет партнёра» (одностраничник для переговоров) — открытый вопрос
([`../program/governance.md`](../program/governance.md) § 14).

## Папки партнёров

Отдельная папка заводится для партнёра с постоянным потоком работы, данных и артефактов.

| Партнёр | Папка |
|---|---|
| Ингосстрах | [`ingosstrakh/`](ingosstrakh/) |
| Спорткомитет СПб | [`komsport-spb/`](komsport-spb/) |
| Геоинтеллект (ООО «ЦПИ») | [`geointellect/`](geointellect/) — сквозной технолог, практика; [страница](geointellect/site/index.html) |

Остальные партнёры пока ведутся внутри своих воркстримов; папку партнёра заводим при
необходимости по образцу `ingosstrakh/`.
