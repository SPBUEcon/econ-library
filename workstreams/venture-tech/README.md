Хочешь в этот воркстрим? Два пути (подробно — [гайд](../../guides/how-to-join.md)):

- **Через репозиторий** — заявка в Issues по шаблону

  [соглашение о входе](../_template/onboarding.md) → роль ([роли](../../roles/README.md)).
