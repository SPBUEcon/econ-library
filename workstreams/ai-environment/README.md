# ИИ, цифровые двойники и симуляции

Сквозная линия про ИИ для всех команд: ИИ-агенты, AI-native подход и ИИ-инструменты в ежедневной
работе над моделями воркстримов. Этот воркстрим — среда для остальных: скилы и промпты для команд
(см. [замысел мастерской](../../program/concept.md), раздел «Как мы работаем — среда и инструменты»).

**К чему идём:** на первом стенде — ИИ-слое геоплатформы Геоинтеллекта — понять, сколько стоят ответ,
консультация и геоотчёт, подготовленные с ИИ, и научиться снижать эту стоимость без потери качества.

## Партнёр

**ИИтех (veai)** — М. Костицин, эксперт (среда, лаборатория). Задачу для стенда приносит
[Геоинтеллект (ООО «ЦПИ»)](../../partners/geointellect/README.md) — пока в согласовании.

## Задача семестра

Провести сквозную ИИ-линию: две лекции М. Костицина и набор ИИ-инструментов для команд. На стенде —
большое задание на семестр [`ga-01`](../../assignments/templates/ga-01-ai-routing-coursework.md):
маршрутизация ИИ-моделей в сервисах геоплатформы — прототип и экономическая модель.

## Что сделать сейчас

**Ближайшие шаги**

1. Согласовать две лекции М. Костицина «ИИ-агенты, AI-программирование, AI-native» (предлагались
   даты 24.09 или 08.10.2026).
2. Собрать ИИ-инструментарий для команд.

**Где нужна помощь** — открытые барьеры стенда:

- Нет эталонного набора гео-задач с известными ответами и машинной проверкой.
- Неизвестно, сколько стоят ответ, консультация и геоотчёт, подготовленные с ИИ.
- Не определено, какие данные можно передавать во внешние модели (персональные данные, коммерческая
  тайна клиента, лицензии на наборы).
- Нет тестового контура для геоотчёта по запросу.

**Задания прямо на занятии**

- Разметить синтетические обращения клиентов по сложности и чувствительности.
- Поспорить, какой уровень модели нужен для конкретной задачи.

Задания на семестр, включая `ga-01`, — на [стенде](../../stands/geo-ai-agent/README.md).

## Как присоединиться

Это среда для всех команд: включиться можно отдельно или прямо из своего воркстрима.

- **Записаться** — [форма записи на витрине](https://spbuecon.github.io/econ-library/program/site/workstreams_board.html?ws=ai-environment#apply): воркстрим уже выбран,
  остаётся выбрать формат участия и рассказать о себе. Форма откроет на GitHub готовую заявку,
  ответ придёт комментарием в ней. Когда участие подтвердят, заполните
  [соглашение о входе](../_template/onboarding.md).
- **Прийти на занятие** — задание прямо на занятии (см. выше).
- **Написать** — шерпа уточняется; пока — через куратора, ИИтех (veai), М. Костицин.

Как всё устроено — в [гайде для студента](https://spbuecon.github.io/econ-library/guides/).
