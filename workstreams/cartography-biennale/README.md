# Экология / данные — Биеннале карт

Всероссийский конкурс по картографии и геоаналитике с выставкой работ. Победителей и призов нет,
участие бесплатное, лучшие работы отбирают на выставку. Событие проводим вместе с Геоинтеллектом.

**К чему идём:** уточняется вместе с партнёром.

| | |
|---|---|
| **Уровень** | событие — конкурс и выставка |
| **Статус** | даты уточняются |
| **Стенд** | пока нет |
| **Кто приходит** | оба курса и студенты других вузов |

## Партнёр

**Геоинтеллект** — Д. Структов. Геоинтеллект — эксперт и организатор события; сейчас ищет
практиканта. Подробнее — в [карточке Геоинтеллекта](../../partners/geointellect/README.md).

Подготовить конкурс и выставку. Даты события и роль студентов определяются вместе с партнёрами и
участниками.

## Как присоединиться

- **Подать заявку** — [форма на GitHub](https://github.com/SPBUEcon/econ-library/issues/new?template=join-workstream.yml&title=%5B%D0%92%D1%85%D0%BE%D0%B4%5D%20%D0%AD%D0%BA%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%8F%20/%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5%20%E2%80%94%20%D0%91%D0%B8%D0%B5%D0%BD%D0%BD%D0%B0%D0%BB%D0%B5%20%D0%BA%D0%B0%D1%80%D1%82%20%E2%80%94%20):
  выберите в списке «cartography-biennale — №7 Экология / данные — Биеннале карт» и роль. Ответ
  придёт комментарием в заявке. Когда роль подтвердят, заполните
  [соглашение о входе](../_template/onboarding.md).
- **Написать куратору события** — Геоинтеллект, Д. Структов.

Это событие, поэтому роль студентов определяется под него. Как всё устроено — в
[гайде для студента](https://spbuecon.github.io/econ-library/guides/).
