  подтвердят, заполните [соглашение о входе](onboarding.md).

## Где что лежит

- [`data/raw/`](data/raw/) — исходные данные, не меняются.
- [`data/processed/`](data/processed/) — обработанные данные с описанием, что сделано.
- [`meetings/`](meetings/) — итоги встреч (`ГГГГ-ММ-ДД-meeting.md`).
- [`deliverables/`](deliverables/) — результаты.
- [`workstream.yml`](workstream.yml) — паспорт: строка в [карте воркстримов](../README.md).
