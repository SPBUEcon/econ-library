## Как включиться

Два пути (подробно — [гайд «Как включиться»](../../guides/how-to-join.md)):

- **Через контакт** — напишите шерпе / капитану / владельцу воркстрима (см. поля выше и раздел
  «Команда»).
- **Через репозиторий** — заявка в Issues по шаблону
  [«Заявка на вход»](../../.github/ISSUE_TEMPLATE/join-workstream.md) →
  [соглашение о входе](onboarding.md) → роль.

Открытые для входа новых команд гейты — **G2 и G4** ([модель гейтов](../../program/gates.md)).

## Разделы папки

- [`gates/`](gates/) — артефакты гейтов G0–G5.
- [`data/raw/`](data/raw/) — сырые данные, неизменны.
- [`data/processed/`](data/processed/) — обработанные данные с описанием.
- [`meetings/`](meetings/) — итоги встреч (`ГГГГ-ММ-ДД-meeting.md`).
- [`deliverables/`](deliverables/) — результаты и продукты хода.
