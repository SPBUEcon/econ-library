## Суперзадача

**Длинный горизонт (вызов Спорткомитета).** Построить **сквозную систему управления** «от верхних
показателей до нижних локальных событий и активов»: инфраструктура и событийность связаны с каналами
коммуникации, обратной связью и запросами жителей в единый управляемый контур. Сегодня стратегии
коммуникации нет, каналы управляются слабо, обратная связь (медиасрез, настроения, отклики, запросы)
не анализируется — и вложения в инфраструктуру/события слабо связываются с аудиторией. Развёрнуто —
[`partners/komsport-spb/tasks/task-2-engagement.md`](../../partners/komsport-spb/tasks/task-2-engagement.md).

## Результат хода (короткий горизонт)

«**Аудит каналов, медиасрез и прототип сквозной системы показателей**»:

- инвентаризация каналов Комитета и активов (портал, соцсети, СМИ, событийные площадки): аудитория,
  что публикуется, как измеряется;
- **медиасрез** по открытым данным — тональность, охваты, отклики на форматы/события, запросы и
  «боли» жителей (без персональных данных);
- **карта разрывов** «актив/событие → канал → аудитория → обратная связь»;
- **прототип сквозной системы показателей** (верх: информированность, вовлечённость,
  удовлетворённость → низ: охват события, отклик по каналу) + черновик стратегии управления каналами.

*Форма:* исследование/аудит + модель показателей + черновик стратегии. *Масштаб:* команда (+
мини-треки). *Приёмщик:* носитель ставки (Спорткомитет) + шерпа + мастер. *Вердикт:* «беру / беру с
условиями / не беру».

> **ИИ** — для мониторинга медиа и соцсетей, кластеризации откликов и запросов (переопыление с
> [`ai-environment`](../ai-environment/)). Только открытые источники, без персональных данных.

## Ближайшее действие

1. Встреча с Спорткомитетом: доступ к данным по каналам/событиям и медиаметрикам; согласовать, что
   считаем «верхними» и «нижними» показателями.
2. Запустить мини-трек «инвентаризация каналов + первый медиасрез» — вход студентов + материал для
   рамки G0.
3. Зафиксировать **мандат G0** (проблемное поле · границы «что снаружи» · критерии · горизонт),
   назвать шерпу → пройти G0. Черновик — [`gates/g0-mandate-2026-09-23.md`](gates/g0-mandate-2026-09-23.md).

План работ хода — [`plan-osen-2026.md`](plan-osen-2026.md).
