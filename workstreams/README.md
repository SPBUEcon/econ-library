# Карта воркстримов

**Воркстрим** — тематическое направление, в котором команды решают реальную задачу и идут к
конкретному результату. Тема живёт дольше семестра: команды сменяются, работа продолжается.

**[Витрина воркстримов →](https://spbuecon.github.io/econ-library/program/site/workstreams_board.html)** ·
**[Подать заявку →](https://github.com/SPBUEcon/econ-library/issues/new?template=join-workstream.yml)** ·
[Как включиться](../guides/how-to-join.md)

## Воркстримы

Уровень: **A** — работа идёт в этом семестре · **B** — флагман: большая тема на год и дольше,
студенты входят в неё отдельными задачами · **сквозной** — идёт через все команды · **событие** —
конкурс или форум · **прото** — тема ищет партнёра.
