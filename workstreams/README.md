## Легенда

- **Уровень A** — оперативный воркстрим на семестр (доходит до G3–G4 этой осенью).
- **Уровень B** — флагман длинного горизонта (этой осенью только G0–G2: рамка → архитектура).
- **Гейты:** G0 Рамка · G1 Команда · G2 Архитектура · G3 Поле · G4 Результат · G5 Наследование.
- **Роли партнёра:** Владелец воркстрима · Эксперт · Шерпа · Кадровый потребитель
  (см. [`../roles/README.md`](../roles/README.md)).
- **Статусы:** Решено · В процессе / требует заполнения · В процессе утверждения ·
  В процессе переговоров.
