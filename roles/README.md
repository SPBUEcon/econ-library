# Роли Мастерской «Технологии в экономике»

> **Источник:** проект «мастерская образования» (Claude cowork), концепт (раздел «Роли в
> команде» и архитектура слоёв) + легенда карты воркстримов; извлечено 2026-09-18. Оригиналы —
> [`../program/source/`](../program/source/).

Роли распределяются по трём слоям архитектуры (см. [`../program/concept.md`](../program/concept.md)).

## Роли по слоям

| Слой | Роли |
|---|---|
| Программа · курс | **Мастер** + факультет |
| Воркстрим | **Шерпа** + партнёр |
| Команды и участники | **Капитан** + студенты |

## Роли в команде

| Роль | Ответственность |
|---|---|
| **Капитан** | Ведёт командный ход по гейтам G0→G5, отвечает за пакет наследования |
| **Аналитик** | Модели, рынки, данные |
| **ГИС-специалист** | Геоаналитика и карты |
| **Разработчик** | Инструменты и прототипы |
| **Маркетинг и коммуникации** | Продвижение, медиа, коммуникация с партнёром |

Один участник может совмещать роли; личная траектория ведётся в диалоге с мастером и шерпой.
Вклад виден через цифровой след: коммиты, артефакты гейтов, участие — основа оценки.

## Роли партнёра

Из легенды карты воркстримов ([`../workstreams/README.md`](../workstreams/README.md)):

| Роль партнёра | Что означает |
|---|---|
| **Владелец воркстрима** | Носитель суперзадачи с реальной ставкой; для флагмана — владелец флагмана |
| **Эксперт** | Даёт лекции и экспертизу по теме воркстрима |
| **Шерпа** | Проводит команду через поле: инструмент, данные, методология |
| **Кадровый потребитель** | Заинтересован в выпускниках / результатах как работодатель |

## Мастер и шерпа

- **Мастер** — ведёт программу и ритм семестра, держит архитектуру мастерской.
- **Шерпа** — сопровождает воркстрим: связывает команду с партнёром, даёт инструменты и данные,
  помогает пройти гейты. Может быть шерпой-технологом (например, ГИС-технолог в воркстриме
  «Развитие территорий»).
