# Командная работа

- У каждого кейса есть README с составом команды, ролями и сроками.
- Задачи — через Issues, обсуждения — в комментариях к ним, чтобы решения не терялись в мессенджерах.
- Итоги встреч записываются в `meetings/` в формате `ГГГГ-ММ-ДД-meeting.md`: участники, решения, кто что делает к какому сроку.
- В ветку `main` изменения попадают только через Pull request с проверкой.
