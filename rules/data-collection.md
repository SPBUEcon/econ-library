# Сбор данных

- Только открытые источники: официальная статистика, раскрытие информации компаний, отраслевые отчёты, публикации СМИ.
- Не собирать персональные данные (ФИО, контакты, отзывы с именами).
- Соблюдать правила сайтов-источников.
- Для каждого набора данных фиксировать: источник (ссылка), дату получения, кто собрал.
- Сырые данные хранятся в `data/raw/` без изменений.
- Очищенные и обработанные данные — в `data/processed/`, с описанием, что было сделано.
- Формат таблиц: CSV или XLSX. В первой строке — названия столбцов, единицы измерения указывать в названии: `premiums_mln_rub`.
