## План хода

Курс ИСЭ (4 к.) идёт **параллельно** основному ходу: гейты общие (G0→G5), **даты у команд свои и
уточняются** (см. [`../../../program/calendar.md`](../../../program/calendar.md)). Расписание занятий
трека — по мере проведения в [`sessions.md`](sessions.md).

| Гейт | Что происходит | Дата |
|---|---|---|
| G0 — Рамка | Вход в ландшафт, сборка воркстримов, суперзадачи | *уточнить* |
| G1 — Команда | Формирование команд, роли, наследство | *уточнить* |
| G2 — Архитектура | Защита концепции живой модели | *уточнить* |
| G3 — Поле | Проверка модели реальной средой | *уточнить* |
| G4 — Результат | Промежуточная защита проектов | *уточнить* |
| G5 — Наследование | Пакет передачи следующей команде | *уточнить* |
