## План хода

Курс ИСЭ (4 к.) идёт **параллельно** основному ходу: события общие, **даты у команд свои и
уточняются** (см. [`../../../program/calendar.md`](../../../program/calendar.md)). Расписание занятий
трека — по мере проведения в [`sessions.md`](sessions.md).

| Что происходит | Дата |
|---|---|
| Вход в ландшафт, знакомство с воркстримами | *уточнить* |
| Формирование команд, роли, наследство | *уточнить* |
| Интенсив Спорткомитета — мост стенда [`geo-sport-spb`](../../../stands/geo-sport-spb/README.md) | 21.10.2026 |
| Открытая встреча в Музее спорта | 29.10.2026 |
| Демо-день — городская спортивная площадка | 16.12.2026 |
| Передача наследства | после хода |

Гейты отменены 2026-10-09 — [архитектура](../../../program/architecture.md). Команды потока держат
слой Ф (фундамент ИС) стенда.
