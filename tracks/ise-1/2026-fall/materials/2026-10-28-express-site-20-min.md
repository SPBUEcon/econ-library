# Стресс-тест · хард-версия: сайт в интернете за 20 минут

Экспресс-задание на занятии 28.10.2026, группа 26.Б03-э ([`ise-1`](../../README.md), осень 2026).
Источник — документ преподавателя «Задание_сайт_за_20_минут_хард_v2.docx» (перенесён в markdown без изменений
по содержанию, 2026-10-28).

## Задача

За 15–20 минут опубликуйте в интернете свой одностраничный сайт на бесплатном домене, используя только
бесплатные инструменты: GitHub — для хранения кода, Vercel — для публикации. Код можно сгенерировать в любом
ИИ-чате или взять любой готовый. Пошаговой инструкции нет: проверяется умение самостоятельно разобраться в
незнакомых сервисах. Пользоваться можно чем угодно — поиском, ИИ, документацией сервисов, но не помощью соседей.

## Ключевые шаги

1. Зарегистрироваться на GitHub.
2. Зарегистрироваться на Vercel.
3. Собрать код страницы: один файл `index.html`.
4. Создать проект (репозиторий) на GitHub и выложить туда код.
5. Создать проект на Vercel и подключить его к репозиторию GitHub.
6. Опубликовать сайт и получить ссылку вида `….vercel.app`.

## Итоговый результат

Отправить преподавателю две ссылки:

- на сайт — `https://….vercel.app`;
- на репозиторий — `https://github.com/…/…`.

В сообщении указать время старта и финиша.

**Дополнительно, +1 балл.** Подключить к репозиторию ИИ-агента (Claude Code, Codex, Jules, GitHub Copilot или
аналог) и через него внести изменение на сайт. Сдать ссылку на это изменение.

**Застряли?** Если не получается продвинуться дальше 5 минут, сообщите преподавателю — вам вышлют подробную
инструкцию к текущему шагу. Использование подсказки фиксируется в результате.
