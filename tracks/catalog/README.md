# Каталог академического контура: группы, предметы, расписание

Формальная сторона треков — кто, что и когда по расписанию вуза. Источник правды для дат, времени,
мест и состава групп на занятии. Содержание занятий (тема, материалы) — в `sessions.md` прогона трека.

## Модель

```
группа (курс, специальность) ──┐
                               ├── занятие (дата, время, тип, место) ── предмет ── трек ── дисциплина
группа ────────────────────────┘
```

- **Группа** — учебная группа вуза: номер (`24.Б07-э`), год набора, курс, специальность.
- **Предмет** — как он называется в расписании вуза (`Применение информационных технологий в
  экономике и финансах`). Предмет может опираться на **дисциплину** — кросс-семестровую базу знаний
  в [`../../disciplines/`](../../disciplines/README.md).
- **Занятие** — одна строка расписания: дата, время, предмет, тип, формат, место и **несколько групп
  сразу** (поле `group_ids` через `;`).
- **Трек** — предмет × поток групп; у трека есть страница с расписанием и контентом занятий.

Номера групп — не персональные данные ([`../README.md`](../README.md), «Приватность»). ФИО студентов
сюда не пишутся.

## Файлы

| Файл | Строк | Поля |
|---|---|---|
| [`groups.csv`](groups.csv) | 12 | `group_id`, `admission_year`, `course`, `specialty`, `semester_id`, `subject_ids`, `track_id`, `source`, `note` |
| [`subjects.csv`](subjects.csv) | 3 | `subject_id`, `title`, `discipline_id`, `track_id`, `teacher`, `source`, `note` |
| [`schedule-2026-fall.csv`](schedule-2026-fall.csv) | 34 | `date`, `time_start`, `time_end`, `subject_id`, `lesson_type`, `format`, `address`, `room`, `group_ids`, `source` |

Источники: `timetable-2026-fall` — скриншоты расписания СПбГУ от 2026-10-09 ([`../data/raw/`](../data/raw/README.md));
`owner-2026-10-09` — со слов преподавателя (прошедшие занятия, которых нет в снимке). Пустое поле — нет в
источнике, *уточнить*.

**Специальность в расписании** не дублируется: занятие ссылается на группы, а курс и специальность берутся из
`groups.csv` — так их показывает страница трека («24.Б07-э … · 3 курс · Экономика»).

## Как обновлять

1. Новый снимок расписания — в `../data/raw/` с датой в имени.
2. Поправить `schedule-2026-fall.csv` (и `groups.csv`, если изменился состав).
3. Пересобрать страницу трека: `python tracks/econ-3/site/build.py` — блоки «время · группы · курс и специальность · место» на
   карточках занятий собираются из расписания. Если у даты из расписания нет карточки, сборка
   остановится и назовёт дату.
