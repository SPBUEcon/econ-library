# Треки: группы × семестры

**Трек** — формальная академическая единица: дисциплина, которую читают конкретному потоку/курсу
(нескольким учебным группам вместе) в вузе. Это **академический контур** мастерской (расписание,
занятия, доклады, отчётность) — параллельный рабочему контуру воркстримов.

> Заведено решением владельца (Д. Хан, 2026-09-24): нужно место, куда складывать данные по уже идущим
> потокам. Граница с рабочим контуром — ниже.

## Модель

Как и воркстрим, трек — **устойчивая единица**, живёт дольше семестра; семестр — один **прогон**.

```
трек (дисциплина × поток, живёт годами)
  └── прогон (один семестр: план, занятия, доклады, отчётность)
```

- Папка трека — латиница, нижний регистр, дефис: `econ-3`, `bi-4`.
- Папка прогона — `semester_id` как в реестре: `2026-fall`, `2027-spring`
  (см. [`../registry/README.md`](../registry/README.md), [`../CONTRIBUTING.md`](../CONTRIBUTING.md)).

## Приватность и границы

- **Репозиторий публичный.** Персональные данные студентов (ФИО, контакты) сюда **не пишутся**
  ([`../rules/data-collection.md`](../rules/data-collection.md)).
- **Пофамильная посещаемость и оценки — не здесь.** Это вузовская ведомость; сюда идут только
  агрегаты (сколько было, сколько сдали) и ссылка на вузовский контур
  ([`../registry/README.md`](../registry/README.md), раздел «Что сюда не пишется»).
- **Номера учебных групп** — не персональные данные, их указывать можно.
- Незаполненные данные помечаются «*заполнить*» — не выдумываются
  ([`../CLAUDE.md`](../CLAUDE.md), «Не придумывай данные»).
