# Если не получается с GitHub или Vercel

Справка для заданий, где нужен публичный репозиторий или опубликованная страница: [`tpl22`](../templates/tpl22-first-forecast.md)
«Первый прогноз», [`tpl23`](../templates/tpl23-group-data-chart.md) «Данные группы на графике»,
экспресс-задание [«Сайт в интернете за 20 минут»](../../tracks/ise-1/2026-fall/materials/2026-10-28-express-site-20-min.md).

Не пришло письмо, не открывается сайт, не принимает почту или телефон — не ждите, возьмите альтернативу.
Задание засчитывается на любой площадке из таблицы, если репозиторий публичный и ссылка открывается без входа.

## Что выбрать

| Задача | Основная площадка | Альтернатива | Ещё альтернатива |
|---|---|---|---|
| Репозиторий: код, CSV, карточка | [GitHub](https://github.com) | [GitVerse](https://gitverse.ru) | [SourceCraft](https://sourcecraft.dev) |
| Публикация страницы из репозитория | GitHub Pages | GitVerse Pages | SourceCraft Sites |
| Публикация страницы без регистрации | — | [Netlify Drop](https://app.netlify.com/drop) — только чтобы показать на занятии | — |
| Публикация как в «Сайте за 20 минут» | [Vercel](https://vercel.com) | GitVerse Pages или SourceCraft Sites | Netlify Drop |

Карточки прогнозов однокурсников уже лежат на GitVerse и SourceCraft — эти площадки работают.

## Как опубликовать страницу

**GitHub Pages.** Репозиторий → **Settings → Pages → Deploy from a branch → main / (root) → Save**. Адрес:
`<ник>.github.io/<репозиторий>/`.

**GitVerse Pages.** Репозиторий публичный → **Настройки → Страницы** → включить → источник **«Ветка»** →
ветка `main` или `master`, папка `/` → сохранить. Сборка и публикация запустятся сами. Главный файл —
`index.html` в корне. Адрес: `https://<ник>.gitverse.site/<репозиторий>`. Нужно, чтобы в репозитории
был включён CI/CD, а в нике не было точек.

**SourceCraft Sites.** Репозиторий должен быть публичным **и** лежать в публичной организации. В корень
положите файл `.sourcecraft/sites.yaml` с одной строкой `site:` — тогда сайт публикуется из корня
основной ветки. Главный файл — `index.html`. Адрес: `https://<организация>.sourcecraft.site/<репозиторий>`.
Проще всего начать с шаблона **sites-landing** при создании репозитория.

**Netlify Drop.** Откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите папку с
`index.html` и CSV. Сайт появится сразу, без аккаунта, но временно и под паролем, пока вы не войдёте в
аккаунт Netlify. Для показа на занятии подходит, для сдачи — нет: сдаётся репозиторий.

## Что изменится в задании

- **Ссылки.** Сдавайте ссылки той площадки, где лежит работа. В README или карточке напишите, какая это
  площадка.
- **Темы репозитория** (`econ-forecast`, `vbi-2026`). Если на площадке нет тем, впишите их в описание
  репозитория.
- **Соавторы при работе в группе.** На любой площадке — в настройках доступа репозитория.
- **Переезд.** Перенесли работу на другую площадку или переименовали репозиторий — сообщите новую ссылку
  (для прогнозов — в [реестр карточек](../forecast-cards/README.md#реестр-и-актуализация)).

## Если не работает ничего

Покажите работу с ноутбука и опубликуйте её дома по другой сети. С мобильного интернета адреса
`github.io` и другие бывают недоступны — проверьте по Wi-Fi.
