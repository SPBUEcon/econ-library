# Досье · Спорт Санкт-Петербурга

Досье для прикладных тем Мастерской по пулу задач Комитета по физической культуре и спорту
Санкт-Петербурга. Объект досье — городская система спорта: инфраструктура (предложение),
коммуникация (спрос) и обратная связь. Темы очереди 1 закладывают данные и первые модели, темы
очереди 2 опираются на их результаты. Так работа студенческих команд накапливается от семестра к
семестру, а не начинается заново.

## Стадии этого досье

Общая шкала — [`../README.md`](../README.md). Для городской системы спорта она читается так:

| Стадия | Признак |
|---|---|
| **Зерно** | Есть стратегия и пул задач; данных по объектам, каналам и событиям в досье нет |
| **Каркас** | Приняты результаты очереди 1: реестр и атлас пилотного района, аудит каналов, медиасрез, разбор событий |
| **Модель** | Собраны модели на каркасе: система показателей вовлечения, экономика участков, требования к публичной карте |
| **Кейс** | Модели прошли проверку Комитетом (вердикт на демо-дне) и переопылены на другие районы или воркстримы |

## Как взять задание

1. Посмотреть стадию досье и [доску пробелов](open-questions.md).
2. Взять задание у преподавателя; объект (город-аналог, район, события, участки) согласовать с
   куратором Комитета. Выдача записывается в [`issues.csv`](../../catalog/issues.csv) с версией
   досье (`sport-spb@v0`).
3. Данные и продукт сдаются PR в папку своего воркстрима (`data/`, `deliverables/`); в
   [`contributions/`](contributions/) — короткая записка со ссылками, в [`model.md`](model.md) — что
   изменилось в модели.
4. При приёмке куратор поднимает версию и пишет строку в [`changelog.md`](changelog.md).
