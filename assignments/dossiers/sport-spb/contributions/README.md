# Спорт Санкт-Петербурга — сданные работы

Сюда кладутся короткие записки по заданиям досье. Имя файла: `<semester_id>-<ник или team_id>-<template_id>.md`,
например `2026-fall-team03-sp-06.md`. Без ФИО, только ник или `team_id`.

Сами данные и продукт лежат в папке воркстрима (`workstreams/<воркстрим>/data/`, `deliverables/`).
В записке укажите:

- выдачу (`issue_id` из [`issues.csv`](../../../catalog/issues.csv)) и версию досье, от которой шли;
- ссылки на данные и продукт в воркстриме;
- что изменили в [`model.md`](../model.md) и [`open-questions.md`](../open-questions.md);
- где использовали ИИ и что проверили по первоисточнику.
