# Досье · Red Bull

Эстафетное досье по кейсу Red Bull. Кейс разбирается в дисциплине
[«Технологии (ИСЭиФ)»](../../../disciplines/technologies-econ-fin/README.md) на лекциях и семинарах.
Компания продолжает меняться, поэтому разбор не пишется один раз, а накапливается: каждый участник
принимает досье в текущем состоянии, делает свой шаг и передаёт дальше.

## Маршрут заданий

Какое задание выдаётся, зависит от стадии досье (правила — [`../../README.md`](../../README.md),
«Как задание корректируется накопленным»). Все задания — в
[`../../catalog/templates.csv`](../../catalog/templates.csv).

| Стадия досье | Задание | Навыки | Кому подходит |
|---|---|---|---|
| Зерно → каркас | `rb-01` Каркас и хроника: проверить цифры `bm01`/`ca08`, собрать хронику трансформаций | Поиск, данные | Любой трек; хороший вход |
| Любая | `tpl13` Микро-задание с [доски пробелов](open-questions.md) | Поиск | Добор, новичок |
| Зерно → модель | **[`rb-02` Бизнес-модель по трём укладам](../../templates/rb-02-red-bull-business-model.md)** (карточка): проверка тезисов слайдов + модель | Поиск, анализ, модель | `econ-3`, `bi-4` |
| Каркас и выше | `rb-07` Дашборд хроники и модели | Разработка, данные | `bi-4` |
| Модель | `rb-04` Оппонирование: где Red Bull не уровень 3 | Оппонирование | Любой трек |
| Модель | `rb-05` Ставка «следующая хлопушка» | Ставка | Любой трек |
| Модель | `tpl10` Дебаты по спорному тезису модели | Организация, коммуникация | Команда |
| Модель → кейс | Обновление строки `bm01` в каталоге дисциплины по итогам досье | Наследование | Куратор + участник |
| Кейс | `rb-06` Переопыление на партнёра спортивного воркстрима | Модель | Команда воркстрима |
| Модель или устарело | `rb-03` Актуализация: что изменилось с последней версии | Поиск, наследование | Следующий семестр |

**Одна тема — разные навыки.** В одном семестре над досье могут работать одновременно: один собирает
хронику (`rb-01`), другой строит дашборд по мере её роста (`rb-07`), команда готовит дебаты по будущей
модели. Результаты стыкуются через общие CSV.

## Как взять задание

1. Посмотреть стадию и [доску пробелов](open-questions.md).
2. Взять задание у преподавателя или забронировать пробел; выдача записывается в
   [`issues.csv`](../../catalog/issues.csv) с версией досье (`red-bull@v0.1`).
3. Работать в ветке `ник/red-bull-<что>`; сдать PR в эту папку, работу — в
   [`contributions/`](contributions/).
4. При приёмке куратор поднимает версию и пишет строку в [`changelog.md`](changelog.md).

## Оговорка

Стартовое содержание (v0.1) — тезисы авторских слайдов Д. Хан и извлечение каталога дисциплины. Цифры
вторичны и не проверены. Задача досье — заменить их проверенными данными из первоисточников.
