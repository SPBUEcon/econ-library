# Red Bull — сданные работы

Сюда кладутся работы по заданиям досье. Имя файла: `<semester_id>-<ник>-<template_id>.md`, например
`2026-fall-nick-rb-01.md`. Без ФИО, только ник или `team_id`.

В начале файла укажите:

- выдачу (`issue_id` из [`issues.csv`](../../../catalog/issues.csv)) и версию досье, от которой шли;
- что изменили в `model.md`, `timeline.csv`, `open-questions.md`;
- где использовали ИИ и что проверили по первоисточнику.
